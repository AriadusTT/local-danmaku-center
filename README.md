# local-danmaku-center

本地弹幕中心

**管理本地弹幕：支持从多个来源导入弹幕，经去重、清洗、时间轴校准后统一入库；播放器按本地条目读取已治理的结果。**

当前进度：施工中

---

## 路线图

| 阶段 | 内容 | 状态 |
|---|---|---|
| 一 · 媒体库索引 | Emby 连通与配置、分页扫描（全量 / 增量）、条目索引与差量、卡片墙控制台、运行日志、定时任务 | ✅ 已完成 |
| 二 · 弹幕资产入库 | 扫描媒体目录已有 `.xml` / `.ass`、手动导入、按剧与集的覆盖率视图 | ⏳ 下一步 |
| 三 · 清洗流水线 | L1 精确去重、L2 近似去重、L3 刷屏抑制、L4 内容过滤、L5 密度控制 | ⏳ 计划中 |
| 四 · 时间轴校准 | 单集偏移设置与实时预览、偏移按 `(剧集, 季, 源)` 记忆、密度曲线辅助对齐 | ⏳ 计划中 |
| 五 · 多源合并 | 合并策略、`source` 来源溯源、按源开关、合并回滚 | ⏳ 计划中 |
| 六 · 输出 | JSON 格式（含 `schema_version`）、按需导出、播放器读取接口（仅本机） | ⏳ 计划中 |
| 七 · 可选远程源 | B 站 adapter、弹弹play adapter（有凭证才启用，无凭证时不影响其他功能） | ⏳ 计划中 |
