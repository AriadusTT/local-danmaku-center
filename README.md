# local-danmaku-center

本地弹幕中心

**管理本地弹幕：支持从多个来源导入弹幕，经去重、清洗、时间轴校准后统一入库；播放器按本地条目读取已治理的结果。**

当前进度：施工中

---

## 路线图

| 阶段            | 内容                                                    | 状态    |
| ------------- | ----------------------------------------------------- | ----- |
| 一 · 媒体库索引     | Emby 连通与配置、分页扫描（全量 / 增量）、条目索引与差量、卡片墙控制台、运行日志、定时任务     | ✅ 已完成 |
| 二 · 本地媒体与弹幕匹配 | 请求前优先进行id匹配与记录，后续再次使用可直接匹配                            | ⏳ 施工中 |
| 三 · 远程源弹幕请求   | B 站 adapter、弹弹play adapter（有凭证才启用，无凭证时不影响其他功能）        | ⏳ 计划中 |
| 四 · 弹幕聚合与清洗   | 精确去重、近似去重、刷屏抑制、内容过滤、密度控制、合并策略、`source` 来源溯源、按源开关、合并回滚 | ⏳ 计划中 |
| 五 · 输出        | JSON 格式（含 `schema_version`）、按需导出                      | ⏳ 计划中 |
| 六 · 弹幕缓存      | 缓存弹幕，短期内直接返回减少api请求                                   | ⏳ 计划中 |
